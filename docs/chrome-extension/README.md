# Extensión de Chrome de GenScore (CHROME-EXT-1)

Línea nueva propuesta por Denis el 2026-10-25: una extensión de Chrome que junta
SEO y GEO como canal de captación de genscore.es.

Estado: **Task Intake, sin implementar.** Nada se construye hasta que Denis elija
el plan y el nombre de la ficha. Denis se inclina por la alternativa A
(«Estudio», 2026-10-25); la revisión 3 la detalla en el prototipo navegable.

| Fichero | Qué es |

| [`ux-options.html`](./ux-options.html) | Las tres alternativas de UX del panel (Estudio, Mapa, Instrumento), con flujo, pros y contras y esfuerzo |
| [`prototipo-navegable.html`](./prototipo-navegable.html) | Alternativa A navegable: tu web, un rival, una fuente citada y otra web, sin cuenta y con cuenta, conexión y permiso. Incluye el valor por tipo de cliente y qué va al panel y qué a la consola |
